# Практическая работа 23 - Ежедневник для Android

## Описание
DailyPlanner - это мобильное приложение-ежедневник для Android, позволяющее пользователям создавать, сортировать и управлять событиями. Приложение поддерживает отображение событий по дням, неделям и месяцам, а также использует систему уведомлений для напоминания о важных задачах.

## Цель
Разработать мобильное приложение-ежедневник с функциями создания событий и уведомлений для Android.
- **Создание событий** с указанием даты, времени, важности и описания.
- **Сортировка событий** по дате и важности.
- **Цветовая маркировка** в зависимости от приоритета события.
- **Отображение событий** в виде списка (день/неделя/месяц).
- **Система уведомлений** с использованием `AlarmManager` и `NotificationManager`.
- **Отображение уведомлений** в статус-панели Android.
